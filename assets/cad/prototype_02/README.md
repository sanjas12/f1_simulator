# Второй прототип — макет FreeCAD

Создан по рисунку с красными стрелками, 5 сентября 2026 года.

- `Formula_Prototype_02.FCStd` — модель из 44 отдельных твёрдых деталей.
- `Formula_Prototype_02.step` — геометрия для переноса в CAD-программы.
- `build.FCMacro` — Python-макрос построения для установленного FreeCAD.
- `validation.json` — проверка геометрии и размеров.

Размеры: длина 4500 мм, ширина 1800 мм, высота 950 мм. Эти габариты согласованы в разговоре. Колёсная база 2750 мм, диаметр колёс 620 мм, ширина передних шин 250 мм и задних 320 мм — предположения для первого макета. Поперечные сечения, рычаги подвески и внутренность кокпита также приблизительные. Красные стрелки не используются как результаты аэродинамического расчёта.

Откройте FCStd в FreeCAD, выберите аксонометрический вид и команду «Вписать всё». В дереве можно выбирать детали и скрывать их пробелом; попробуйте скрыть нос или колесо. Проверьте силуэт в виде сбоку и ширину в виде сверху.

На этом шаге изучаем построение объёма по поперечным сечениям (loft), вычитание одного тела из другого для кокпита и разбиение машины на детали. В документе сохранены готовые тела, без истории эскизов и параметрических операций. Таблица Dimensions справочная: изменение ячеек не перестраивает модель. Для изменения формы отредактируйте соответствующие размеры и сечения в макросе и запустите его через «Макросы». Макрос перезаписывает выходные файлы в этой папке; перед этим сохраните ручные изменения под другим именем.

Проверка: все 44 тела имеют положительный объём и корректную геометрию; FCStd повторно прочитан через FreeCAD. Проверено изображение вида сверху (`preview.png`). Игровая сцена не менялась.
