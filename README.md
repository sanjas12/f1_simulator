# Formula Simulator

Учебный проект хардкорного 3D-симулятора автомобиля класса Formula. Главная цель — последовательно изучать разработку игр, физическое моделирование автомобиля и работу с игровыми устройствами ввода.

Первая законченная версия проекта будет представлять собой режим хотлапа: одна машина, одна тестовая трасса, таймер круга, телеметрия и поддержка клавиатуры, геймпада и в дальнейшем руля.

> Подготовка окружения завершена. Серый 3D-прототип уже двигается с клавиатуры, при этом чтение ввода отделено от учебной модели движения.

## Начало работы

Godot-проект находится в каталоге `formula_simulator/`. Результаты подготовки окружения и команды самостоятельной проверки находятся в [SETUP.md](SETUP.md).

Не устанавливайте все инструменты одновременно только потому, что они перечислены в стеке. Для первого этапа обязателен только Godot; Python и Blender подключим тогда, когда появится конкретная учебная задача для каждого из них.

## Технологии

- [Godot 4](https://godotengine.org/) — игровой движок и 3D-сцена.
- [GDScript](https://docs.godotengine.org/en/stable/tutorials/scripting/gdscript/) — основной язык игровой логики.
- [Blender](https://www.blender.org/) — создание и подготовка 3D-моделей.
- Python — анализ телеметрии и вспомогательные инструменты.
- Git — контроль версий.

## Основные цели

- Реализовать собственную физическую модель автомобиля на основе `RigidBody3D`.
- Разделить шины, подвеску, тормоза, двигатель, коробку передач и аэродинамику на независимые подсистемы.
- Добавить фиксированный физический шаг и воспроизводимое поведение машины.
- Реализовать трассу с чекпоинтами, таймером и проверкой корректности круга.
- Записывать телеметрию в CSV для последующего анализа в Python.
- Использовать единый слой ввода для клавиатуры, геймпада и будущего руля.

## План первой версии

1. Создать базовый Godot-проект и изучить сцены, узлы, сигналы и физический цикл.
2. Собрать серый прототип машины, трассы и камеры.
3. Реализовать подвеску и базовую модель сил в пятне контакта шин.
4. Добавить двигатель, коробку передач, тормоза и аэродинамику.
5. Добавить чекпоинты, таймер круга, HUD и перезапуск заезда.
6. Реализовать экспорт телеметрии.
7. Подключить геймпад, а после выбора устройства — руль и force feedback.

Полная дорожная карта находится в файле [PLAN.md](PLAN.md).

## Запуск

Чтобы открыть проект:

1. Запустить стандартную версию Godot 4.7.2.
2. В Project Manager импортировать файл `formula_simulator/project.godot`.
3. Открыть проект и нажать `F6` для текущей сцены или `F5` для главной сцены.

Главная сцена находится в `formula_simulator/scenes/main.tscn`. При запуске отображается тестовая поверхность и макет машины, которым можно управлять клавишами `W`, `S`, `A` и `D`.

## Текущий учебный этап

Текущий прототип знакомит с базовыми узлами Godot и первым типизированным GDScript-кодом:

- `Node3D` объединяет связанные объекты и задаёт для них общую систему координат;
- `MeshInstance3D` показывает геометрию, но сам по себе не участвует в столкновениях;
- `StaticBody3D` с `CollisionShape3D` образует неподвижную поверхность для будущей физики;
- `DirectionalLight3D` имитирует далёкий источник света, например солнце;
- `Camera3D` определяет, откуда игрок видит сцену.
- `KeyboardInput` преобразует клавиши в универсальные команды `steering`, `throttle` и `brake`;
- `VehiclePrototype` обновляет движение в `_physics_process()` с фиксированной частотой 60 Гц.

Движение пока кинематическое: скрипт напрямую меняет положение `Node3D`. Оно нужно для изучения ввода, локальных осей и физического цикла, но не имитирует массу, сцепление или подвеску и позже будет заменено собственной моделью на `RigidBody3D`.

Для проверки запустите главную сцену клавишей `F6`, удерживайте `W` для разгона, поворачивайте `A` и `D`, затем удерживайте `S` для торможения. После отпускания клавиш машина должна плавно остановиться из-за учебного сопротивления качению.

## Управление

Планируемая базовая раскладка:

| Действие | Клавиша |
| --- | --- |
| Газ | `W` |
| Тормоз | `S` |
| Поворот | `A` / `D` |
| Повышение передачи | `E` |
| Понижение передачи | `Q` |
| Перезапуск заезда | `R` |
| Пауза | `Esc` |

Раскладка является предварительной и будет настраиваемой.

## Принципы разработки

- Сначала проверяем физику на простых формах, затем улучшаем графику.
- Каждая физическая подсистема должна быть понятной, настраиваемой и проверяемой отдельно.
- Изменения параметров автомобиля должны отражаться в телеметрии предсказуемым образом.
- В проекте не используются лицензированные названия, логотипы и модели команд Формулы 1.
